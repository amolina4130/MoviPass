Sobre mí

Soy desarrolladora del proyecto grupal MoviPass, una aplicación web para la gestión y venta de pasajes de transporte interprovincial en Ecuador. Me enfoco en construir pantallas claras y fáciles de usar, y en trabajar de forma ordenada con Git y control de cambios.

    Cómo construí la selección de asientos

    1. Estructura base

    Página HTML con Bootstrap 5 como punto de partida.

    2. Leyenda y estilos del bus

    Colores para distinguir asientos disponibles, seleccionados y ocupados.

    3. Mapa de asientos

    Generación del mapa con asientos disponibles y ocupados.

    4. Selección con clic

    Cada asiento se puede marcar y desmarcar.

    5. Resumen y total a pagar

    Lista de asientos elegidos y cálculo automático del total.

    6. Evidencias y revisión

    Capturas del avance y fusión del cambio mediante pull request.
